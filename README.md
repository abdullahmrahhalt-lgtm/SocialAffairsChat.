# موظفو مبنى مديرية الشؤون الاجتماعية

نسخة أولية قابلة للبناء من تطبيق أندرويد بواجهة عربية RTL وهوية ذهبية مبنية على شعار الوزارة المرفق.

## الواجهات
- شاشة البداية والشعار
- تسجيل اسم الموظف
- قائمة الموظفين المتصلين
- الأقسام
- المحادثة النصية المحلية (واجهة وتجربة أولية)
- الإعدادات

## البناء في Android Studio
1. فك ضغط المشروع.
2. افتح مجلد `SocialAffairsChat` من Android Studio عبر **Open**.
3. انتظر Gradle Sync حتى يكتمل.
4. اختر **Build > Build APK(s)**.

> هذه النسخة تضبط الواجهة والتجربة الأساسية. الاتصال الحقيقي بين عدة هواتف عبر شبكة Wi‑Fi المحلية يحتاج طبقة شبكة/خادم محلي أو اتصال نظير-إلى-نظير قبل استخدامه فعلياً في العمل.
